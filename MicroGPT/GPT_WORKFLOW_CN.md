# GPT 和 MicroGPT 工作流程详解（中文版）

## 一、GPT 是什么？

GPT (Generative Pre-trained Transformer) 是一个**生成式自回归语言模型**。

### 核心概念
- **自回归**：根据前面的词，一个一个地预测后面的词
- **生成式**：不仅能分类，还能创造新文本
- **预训练**：先在大量文本上学习，再针对特定任务微调

### 简单类比
就像你写作文：
1. 看到"今天天气很"，大脑会预测下一个词可能是"好"、"热"、"冷"等
2. GPT也是这样，但它是从大量文本中学会的统计规律
3. 训练就是让它不断练习"看到前文→猜下一词"，直到猜得准

## 三、关键模块详细解析

### 3.1 Attention 机制（注意力）

```
问题：如何让模型"看到"前面的所有词？

解决方案：Attention（注意力机制）

┌─────────────────────────────────────────┐
│  例子：翻译 "I love you" → "我爱你"      │
│                                         │
│  翻译"爱"时，需要看到"I"和"love"         │
│  Attention 就是计算"每个历史词的重要性"  │
└─────────────────────────────────────────┘

具体步骤：

1) Query, Key, Value 投影
   ┌──────────────────────────────┐
   │  当前 token x:  "love"       │
   │                              │
   │  q = Wq · x  (我要查什么)    │
   │  k = Wk · x  (我能提供什么)  │
   │  v = Wv · x  (我的实际内容)  │
   └──────────────────────────────┘

2) 计算相关性 (Attention Score)
   ┌──────────────────────────────────────┐
   │  历史：["I", "love"]                │
   │                                      │
   │  score("I")   = q·k("I") / √d       │
   │  score("love") = q·k("love") / √d   │
   │                                      │
   │  除以√d 是为了让数值稳定              │
   └──────────────────────────────────────┘

3) 归一化 (Softmax)
   ┌──────────────────────────────────────┐
   │  weights = softmax([score("I"),     │
   │                     score("love")])  │
   │                                      │
   │  例如：[0.3, 0.7]                    │
   │  表示当前更关注"love"                │
   └──────────────────────────────────────┘

4) 加权求和
   ┌──────────────────────────────────────┐
   │  output = 0.3·v("I") + 0.7·v("love") │
   │                                      │
   │  这就是"融合了历史信息"的新表示       │
   └──────────────────────────────────────┘

多头 Attention (Multi-Head)：
┌──────────────────────────────────────────┐
│  为什么需要多头？                         │
│                                          │
│  每个头关注不同的"关系模式"：             │
│  - Head 0: 语法关系（主谓宾）            │
│  - Head 1: 语义关系（近义词）            │
│  - Head 2: 位置关系（前后文）            │
│  - Head 3: 其他模式                       │
│                                          │
│  最后拼接所有头的输出 → 更丰富的表示     │
└──────────────────────────────────────────┘
```

### 3.2 MLP 模块（前馈神经网络）

```
作用：特征变换和信息重编码

结构：
  输入 (n_embd=16)
    │
    ▼
  ┌─────────────────┐
  │  fc1: 16 → 64   │  扩展到4倍维度
  └─────────────────┘
    │
    ▼
  ┌─────────────────┐
  │  ReLU 激活       │  引入非线性
  └─────────────────┘
    │
    ▼
  ┌─────────────────┐
  │  fc2: 64 → 16   │  压缩回原维度
  └─────────────────┘
    │
    ▼
  输出 (n_embd=16)

为什么需要 MLP？
- Attention 擅长"路由信息"（哪里的信息有用）
- MLP 擅长"变换信息"（如何理解这些信息）
- 两者结合才完整
```

### 3.3 残差连接（Residual Connection）

```
问题：网络太深，梯度消失/爆炸

解决：残差连接

普通连接：
  x → [层1] → [层2] → [层3] → 输出
  
残差连接：
  x → [层1] → (+) → [层2] → (+) → [层3] → (+) → 输出
        ↓      ↑       ↓      ↑       ↓      ↑
        └──────┘       └──────┘       └──────┘
          跳过           跳过           跳过

代码：
  x_out = f(x) + x  # 不是 x_out = f(x)
  
好处：
- 梯度可以"高速公路"式直达浅层
- 即使 f(x) 学废了，还有原始 x 保底
- 训练更稳定
```

### 3.4 RMSNorm 归一化

```
作用：稳定每层的输入分布

普通 LayerNorm：
  1. 减去均值  (x - mean)
  2. 除以标准差 / std
  
RMSNorm（更简单）：
  1. 计算均方根: rms = √(mean(x²))
  2. 直接缩放: x / rms

为什么有效？
- 控制了激活值的尺度
- 避免梯度过大/过小
- 让优化器工作更顺畅

代码：
  ms = sum(x² for x in x) / len(x)
  scale = (ms + 1e-5) ** -0.5  # 加1e-5防止除0
  return [xi * scale for xi in x]
```

## 四、Value 自动求导原理

### 4.1 什么是计算图？

```
例子：c = (a + b) * 2

计算图：
        a(2)     b(3)
         │       │
         └───┬───┘
             │
           (+) → t1(5)
             │
        [*2] │
             │
             ▼
           c(10)

每个节点记录：
- 当前值 (data)
- 梯度 (grad)
- 子节点 (children)
- 局部导数 (local_grads)
```

### 4.2 反向传播过程

```
目标：计算 dc/da, dc/db

1) 前向：按计算图计算值
   a=2, b=3 → t1=5 → c=10

2) 反向：按拓扑逆序回传梯度
   
   初始化：c.grad = 1  (损失对自己的梯度)
   
   第一步：c → t1
   ┌──────────────────────────────┐
   │  c = t1 * 2                  │
   │  dc/dt1 = 2  (局部导数)      │
   │  t1.grad += 2 * c.grad = 2   │
   └──────────────────────────────┘
   
   第二步：t1 → a, b
   ┌──────────────────────────────┐
   │  t1 = a + b                  │
   │  dt1/da = 1, dt1/db = 1      │
   │  a.grad += 1 * t1.grad = 2   │
   │  b.grad += 1 * t1.grad = 2   │
   └──────────────────────────────┘
   
   结果：
   - a.grad = 2 (c增加1，a需增加0.5)
   - b.grad = 2 (同理)

验证：
  c = (a+b)*2 = 2a + 2b
  dc/da = 2 ✓
  dc/db = 2 ✓
```

### 4.3 为什么需要拓扑排序？

```
错误的顺序示例：

     a
    ╱ ╲
   t1  t2
    ╲ ╱
     c

如果先处理 t1，再处理 a：
  t1 → a 回传一次
  然后 t2 → a 又回传一次  ❌ 但 a.grad 已被后续节点覆盖

正确做法（拓扑逆序）：
  c → t2 → t1 → a
  
  这样 a 会正确累积来自 t1 和 t2 的梯度：
  a.grad = (来自t1的梯度) + (来自t2的梯度)
```

## 五、Adam 优化器原理

### 5.1 为什么不用简单的 SGD？

```
SGD (随机梯度下降)：
  param -= learning_rate * grad
  
问题：
1. 学习率难选
   - 太大：震荡不收敛
   - 太小：训练太慢

2. 不同参数需要不同学习率
   - 有的梯度大，有的小
   - 一刀切不合理

3. 梯度噪声大
   - 每个样本梯度方向不完全一致
   - 需要"平滑"处理
```

### 5.2 Adam 的改进

```
Adam = Adaptive Moment Estimation

核心思想：
1. 动量 (Momentum)：记住历史梯度方向
2. 自适应学习率：根据梯度历史调整步长

伪代码：
  m = 0  # 一阶矩（梯度均值）
  v = 0  # 二阶矩（梯度方差）
  
  for step in training:
      grad = compute_gradient()
      
      # 1) 更新动量
      m = β₁ · m + (1-β₁) · grad       # 指数移动平均
      v = β₂ · v + (1-β₂) · grad²
      
      # 2) 偏差修正（初期 m,v 偏向0）
      m_hat = m / (1 - β₁^step)
      v_hat = v / (1 - β₂^step)
      
      # 3) 自适应更新
      param -= lr · m_hat / (√v_hat + ε)
                    ~~~~~~   ~~~~~~~~~~~
                    动量       归一化
                    
超参数：
  β₁ = 0.85~0.9   # 一阶动量衰减率
  β₂ = 0.99~0.999 # 二阶动量衰减率
  lr = 0.001~0.01 # 学习率
  ε  = 1e-8       # 数值稳定项

直觉理解：
- m_hat：梯度的"方向指针"，平滑噪声
- v_hat：梯度的"剧烈程度"，大梯度→小步长，小梯度→大步长
- 结合：既有方向，又有自适应步长
```

## 六、训练目标：交叉熵损失

### 6.1 什么是交叉熵？

```
场景：预测下一个词

真实标签：
  P_true = [0, 0, 1, 0, 0]  # 第3个词是正确答案
           [a  b  c  d  e]

模型预测：
  P_pred = [0.1, 0.2, 0.4, 0.2, 0.1]  # 概率分布

交叉熵损失：
  Loss = -∑ P_true · log(P_pred)
       = -(0·log(0.1) + 0·log(0.2) + 1·log(0.4) + ...)
       = -log(0.4)
       ≈ 0.916

直觉：
- 预测对了（c），但概率只有0.4（不够自信）
- 损失惩罚"不确定性"
- 如果 P_pred[c]=0.9，损失只有 -log(0.9)≈0.105

训练目标：
  最小化 Loss → 让正确答案的概率尽可能接近1
```

### 6.2 为什么用 log？

```
数学性质：
1. log(p) 在 p→0 时趋向 -∞
   → 惩罚"把正确答案概率预测成0"的行为

2. log 的导数简单
   d(-log(p))/dp = -1/p
   → 梯度传播计算方便

3. 信息论解释
   -log(p) 表示"惊讶度"
   → 模型越自信（p大），越不惊讶（loss小）
```

## 七、推理采样策略

### 7.1 贪心 vs 随机采样

```
假设模型输出概率：
  a: 0.5
  b: 0.3
  c: 0.2

贪心采样：
  总是选最大概率 → 选 a
  
  问题：
  - 生成结果单调
  - 每次跑都一样
  - 缺乏创造性

随机采样：
  按概率分布随机选
  - 50%选a, 30%选b, 20%选c
  - 有多样性
  - 仍保持合理性（不会选很低概率的）
```

### 7.2 Temperature（温度）

```
logits = [2.0, 1.0, 0.5]

Temperature = 1.0 (原始)
  scaled = [2.0, 1.0, 0.5]
  probs = softmax([2.0, 1.0, 0.5])
        = [0.58, 0.24, 0.18]  # 比较确定

Temperature = 0.5 (低温，更保守)
  scaled = [4.0, 2.0, 1.0]
  probs = softmax([4.0, 2.0, 1.0])
        = [0.71, 0.21, 0.08]  # 更集中于最大值

Temperature = 2.0 (高温，更发散)
  scaled = [1.0, 0.5, 0.25]
  probs = softmax([1.0, 0.5, 0.25])
        = [0.47, 0.29, 0.24]  # 更均匀

应用：
- 创意写作：T=0.7~1.0
- 代码生成：T=0.2~0.5 (要严谨)
- 聊天机器人：T=0.6~0.8
```

## 八、C++ 实现的核心挑战

### 8.1 类型设计

```cpp
// Python 的灵活性
probs = [Value(0.1), Value(0.2), ...]  # 列表推导
loss = sum(losses)  # 直接求和
x = [a + b for a, b in zip(x1, x2)]  # 优雅

// C++ 需要明确类型
vector<Value> probs;
probs.reserve(vocab_size);
for (int i = 0; i < vocab_size; i++) {
    probs.push_back(Value(data[i]));
}

// 运算符重载
Vector operator+(const Vector& a, const Vector& b) {
    Vector result(a.size());
    for (size_t i = 0; i < a.size(); i++) {
        result[i] = a[i] + b[i];
    }
    return result;
}
```

### 8.2 内存管理

```cpp
// Python: GC 自动回收
def forward(...):
    x = compute1()
    y = compute2(x)  # x 自动被 GC 管理
    return y

// C++: 需要显式管理
Vector forward(...) {
```

## 十、常见问题 FAQ

### Q1: 为什么 loss 不下降？
```
检查清单：
☐ 学习率是否太小？试试 0.01
☐ 学习率是否太大？试试 0.001
☐ 梯度是否为 0？打印 params[0].grad
☐ 梯度是否爆炸？检查是否 NaN
☐ 是否忘记 loss.backward()？
☐ 是否忘记清零梯度？
☐ 数据是否有问题？检查 tokenize
```

### Q2: 生成的文本全是乱码？
```
可能原因：
1. 训练步数太少（<500步）
2. 温度设置不合理（试试 0.8）
3. 模型容量太小（试试增加层数）
4. tokenizer 有 bug（检查 decode）
```

### Q3: C++ 版本结果和 Python 不一致？
```
对比检查：
1. 随机种子是否相同？
2. 参数初始化是否一致？
3. 浮点精度（float vs double）
4. 运算顺序（乘法不满足结合律）
5. 逐层打印中间值对比
```

### Q4: 训练太慢怎么办？
```
Python 版本：
  - 本来就慢，纯 Python 没法优化太多
  - 减小 n_embd, n_layer 调试用

C++ 版本：
  - 先确保功能正确
  - 再考虑优化（BLAS, 并行等）
  - 用 -O3 编译优化
```
