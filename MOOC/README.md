### 引用 
- 定义引用时一定要将其初始化成引用某个变量。
- 初始化后，它就一直引用该变量，不会再引用别的变量了
- 引用只能引用变量，不能饮用常量和表达式

## 析构函数
<p>何时调用析构函数:<p>

- (1) 对象在程序运行超出其作用域时自动撤销，撤销时自动调用该对象的析构函数。如函数中的非静态局部对象。<br>
- (2) 如果用new运算动态地建立了一个对象，那么用delete运算释放该对象时，调用该对象的析构函数。<br>

<p>
与复制构造函数不同，编译器总是会为类生成一个析构函数，称为合成析构函数(synthesized destructor)<br>
合成析构函数按对象创建时的逆序撤销每个非静态成员，即它是按成员在类中声明次序的逆序撤销成员的。对于类类型的每个成员，合成析构函数调用该成员的析构函数来撤销对象<br>
需要注意，合成析构函数并不删除指针成员所指向的对象，它需要程序员显式编写析构函数去处理。<br>

## 指针和引用

**简短结论**  
- 在实现层面，引用（reference）通常由编译器用指针或寄存器实现，但在语言语义上引用并不等同于指针：引用不是可重新绑定的可空对象，它有不同的语义约束和用途。换言之：引用“看起来像”指针的简化语法，但并不能在所有语义场景下被指针完全替代，反之亦然。

**关键相似点**
- 两者都能间接访问其他对象（通过地址）。
- 在底层实现上，编译器常用指针来实现引用（因此性能相近）。
- 都可以用于函数参数以避免复制大对象（传引用 / 传指针）。

**关键区别（要点）**
- 绑定与重绑定：
  - 引用在初始化后不可重新绑定（int &r = a; 之后 r 永远指向 a）。  
  - 指针可以随时改变指向（p = &b）。
- 可空性：
  - 引用语义上不能为 null（虽然可以通过不安全手段构造悬空/伪引用）。  
  - 指针可以为 `nullptr`，适合表示“无对象”。
- 必须初始化：
  - 引用必须在定义时初始化。  
  - 指针可以声明不初始化（但要小心未定义行为）。
- 语法与可读性：
  - 引用使用起来像别名（`r` 就像`a`），更自然，调用和成员访问写法简洁。  
  - 指针需要解引用 `*`，检查 `nullptr` 等，语法更“显式”。
- 可变性与修饰：
  - `const` 的含义不同但类似语义（`const int&` 是对常量的引用；`const int*` 是指向常量的指针；`int * const` 是常量指针）。
- 生命周期与延迟绑定：
  - 引用通常用于保证被引用对象存在（例如函数参数绑定到实参）。  
  - 指针适用于需要可选性或后期改变绑定的场景。
- 用于重载/运算符和语义契约：
  - 引用常用于运算符重载、返回值优化（返回 `T&`）、移动语义（`T&&`）等；这些场景对“不可重绑定、像变量”的语义很重要。
- 在模板/转发中的行为：
  - 引用折叠、完美转发（`T&&`）是引用特有的模板特性，指针不能替代这些功能。

**示例对比（直观感受）**

- 引用版本 swap：
```cpp
void swap_ref(int &a, int &b) {
    int tmp = a;
    a = b;
    b = tmp;
}
// 调用： swap_ref(x, y);
```
- 指针版本 swap：
```cpp
void swap_ptr(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
// 调用： swap_ptr(&x, &y);
```
两者可以实现同样功能，但调用语义不同：引用直接用变量名，指针要传地址并在函数里解引用；引用更安全（不能传 nullptr）。

- 返回值示例：
```cpp
int& get_global();   // 返回引用，可用于赋值： get_global() = 5;
int* get_global_ptr(); // 返回指针，用法： *get_global_ptr() = 5;
```
返回引用表达“这是某个现存对象的别名”；返回指针暗示“可能为空或表明所有权/可选性”。

**什么时候必须用指针（引用不能替代）**
- 需要表示“无对象”或“可选”时（用 `nullptr`），必须用指针或 std::optional<T>.  
- 需要在容器中存储/改变指向（例如链表节点的 next 指针需可重定向）。  
- 需要晚绑定、允许重新赋指向（例如可重新连接的图结构）。
- 需要表示“指针的指针”或需要修改调用者的指针本身（比如一个函数要把指针设为指向新分配的内存），引用不能直接替代 `T**`（但可以用 `T*&` 引用到指针本身：`void f(int*& p)` 达到同样目的）。

**什么时候更推荐用引用**
- 函数参数传递（当参数不能为空且不需改指向）优先 `T&` 或 `const T&`（尤其是大对象时避免拷贝）。  
- 运算符重载或语义上“目标应像变量”时使用引用。  
- 完美转发、移动语义中使用引用语法（`T&&` / `T&`）是必须的。

**小贴士 / 常见误区**
- “引用是指针的语法糖” —— 这是一个过度简化的说法，只在实现层面（编译器可能用指针）部分成立，但在类型系统、语义、用法和模板特性上引用提供了不等价的行为。  
- 如果你需要 `nullable` 或 `reseatable`，用指针；如果你需要明确存在并像变量一样操作，优先引用或 `const&`。  
- 要修改函数外的指针本身，可以用引用到指针：`void setToNull(int*& p) { p = nullptr; }`，这是引用与指针结合使用的典型场景。
